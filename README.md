 🌱 Smart Eco Navigator 🚗🌍

 Smart Mobility • AI-Powered Assistance • Sustainable Living

Smart Eco Navigator is an Android application project exploring how Artificial Intelligence and mobile technology can support sustainable living through carpool sharing, eco-friendly transportation concepts, and intelligent assistance.

The project combines Android development, Kotlin, database architecture, and local Large Language Model (LLM) integration concepts to explore technology-driven approaches to environmental awareness and sustainable mobility.

🔗 GitHub Repository:[Smart Eco Navigator](https://github.com/harikaran-07/smart-eco-navigator)

---

🌍 Project Overview

Transportation contributes to fuel consumption, traffic congestion, and greenhouse gas emissions. Carpooling offers a way to make better use of available vehicle space by allowing people travelling along similar routes to share rides.

Smart Eco Navigator explores the potential of combining **carpool sharing, AI-powered assistance, and mobile technology** to encourage more environmentally conscious travel choices.

 🎯 Objectives

* 🚗 Explore carpool sharing to encourage shared transportation.
* 🌱 Promote awareness of sustainable mobility and eco-friendly travel.
* 🤖 Investigate AI-powered assistance for sustainability-related information.
* 🧠 Explore local LLM integration for intelligent assistance.
* 📱 Develop Android application components using Kotlin.
* 🗄️ Explore structured data management and modular application architecture.

💻 Getting Started

Prerequisites

* Android Studio.
* A compatible JDK and Android SDK.
* Git.
* An Android device or emulator.

Clone the Repository

```bash
git clone https://github.com/harikaran-07/smart-eco-navigator.git
```

Navigate to the project directory:

```bash
cd smart-eco-navigator
```

Open in Android Studio

1. Open Android Studio.
2. Select **Open** and choose the cloned project directory.
3. Allow Gradle synchronization to complete.
4. Resolve any missing SDK or dependency requirements.
5. Build and run the application if the current project configuration supports it.

**Note:** Build and runtime requirements depend on the project's current Gradle configuration and implementation.
